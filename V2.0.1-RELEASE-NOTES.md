# LifeOS 2.0.1 — Timing Review & Replacement Logs

## New behavior
- Complete now opens a confirmation dialog with actual start/end date and time, prefilled from the activity's scheduled window. Times are editable and are explicitly confirmed before saving; defaults are not silently counted as measurements.
- Earlier/Later 5, 10, 15, 20, 25, 30, 45, and 50-minute presets relative to scheduled end; end-time nudges −5, −1, +1, +5 minutes. Live duration preview; validates positive intervals up to 24 hours.
- Skip opens a replacement-activity logging dialog using the skipped block's planned window as the default. Save a separately titled/categorized log, or skip without logging. Skipped activity remains skipped and is not counted as performed.
- Previously skipped items expose **Log replacement**.
- Confirmed manual start/end timestamps are used to distribute recorded time across calendar dates (including overnight).
- The existing standalone Log editor supports an end date for overnight entries.
- Existing D1 snapshot schema and Cloudflare Worker remain unchanged; no database migration.

## Deploy
1. Export a JSON backup in LifeOS Settings.
2. Upload the contents of `LifeOS-v2.0.1-Frontend.zip` to the root of the GitHub Pages repository, replacing matching frontend files.
3. Do not redeploy the Cloudflare Worker for this release; it is unchanged.
4. Allow the updated service worker to activate, then refresh the app on PC and iPhone. If you see the old UI, close and reopen the installed PWA.
5. Test Complete and Skip on disposable sample activities, then confirm Time & Attention updates and sync works on the second device.

## Limitations
- Prefilled scheduled times are only a convenience; users must correct them if the actual activity differed.
- Manually entered times are user-reported (medium confidence), not stopwatch-measured.
- If a task has timer intervals, confirming a manually entered time range replaces the timer evidence after confirmation.
