# LifeOS Midnight v1.2 — Experience Update

## Included
- AI Copilot prompt shortcuts using the existing Groq AI review-before-save workflow.
- Smart reshuffle of unfinished timed activities, with a preview and confirmation; no overnight scheduling.
- Shared Spaces: create spaces, add dated plans, export/import a shared-space JSON file between accounts.
- Interactive daily progress ring, gentle motion, hover/press feedback, accessible reduced-motion styling.
- PWA cache bumped for desktop/iPhone updates.

## Shared Spaces limitation
Shared spaces currently support **manual file exchange**, not live cross-account synchronization. This is intentional: the existing Cloudflare `/sync` endpoint is private per account, and exposing personal records would be unsafe. Shared spaces are stored within each user's existing account snapshot. To enable live collaboration, a separate authenticated, membership-checked shared-space API and D1 schema migration are required. Do not advertise real-time shared spaces with this frontend alone.

## Deployment
Back up your current repository and export LifeOS data before replacing files. Upload all files in this ZIP to the repository root. No Worker changes are required. Verify both accounts, AI, cloud sync, and offline PWA caching.
